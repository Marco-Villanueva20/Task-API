# TASK API
**RESTful** API for managing tasks.  
Provides CRUD operations to create, read, update and delete tasks.  
Built with Spring Boot and Clean Arquitecture principles.  

## Technologies
- Java 17
- Maven
- Spring Boot
- Spring Data JPA
- H2 Database
- Lombok

## How to run
1. Clone repository
```git
git clone 

```
2. Run:
 
```bash
mvn spring-boot:run

```
